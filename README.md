# LOOPS-in-C
LEVEL -3 -- LOOPS IN C

This repository contains C programming solutions for loops. All programs take an input `n` from the user and process natural numbers accordingly.

## Included Problems

* **problem21.c**: Displays all natural numbers from 1 to `n`.
* **problem22.c**: Displays all natural numbers from 1 to `n` in reverse order.
* **problem23.c**: Displays all even numbers from 1 to `n`.
* **problem24.c**: Displays all odd numbers from 1 to `n`.

## How to Run the Programs

To compile and execute any file using a GCC compiler, run these commands in your terminal:

```bash
gcc problem21.c -o problem21
./problem21
```
